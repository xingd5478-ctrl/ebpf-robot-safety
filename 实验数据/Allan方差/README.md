# Allan方差数据

## 数据来源
MPU6050三轴陀螺仪2小时静态采集（100Hz采样率，720K帧/轴）

## 噪声系数（论文表2.1）
| 轴 | ARW (°/√h) | BI (°/h) | RRW ((°/s)/√h) |
|----|-----------|----------|----------------|
| X  | 5.847     | 0.312    | 4.892          |
| Y  | 5.923     | 0.298    | 5.134          |
| Z  | 6.021     | 0.287    | 6.311          |

## 原始数据
- 720K帧/轴 × 3轴 = 2,160,000条角速度数据
- 当前不可在线重新采集（需STM32+MPU6050硬件连接）
- 论文中的Allan标准差曲线：参见 论文/thesis/figures/allan_variance.pdf

## 关键工程参数
- ARW → R (测量噪声协方差): 100 → 0.91 (Allan校正)
- RRW → Q (过程噪声协方差): 经验值 → Allan标定值
- R/Q校正因子: 100 → 0.91 (约110x校正)
- 200次蒙特卡洛仿真: R/Q误差 +29.9%，校正后R/Q=1.18仍远优于经验默认值100
